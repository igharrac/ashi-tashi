# Backup: originele man-opnames (echte stem) — 2026-09-01

Snapshot van 6 echte, ongewijzigde man-opnames + hun manifest-entries
(kleuren-blauw, kleuren-rood, oefenen-waar-ga-je-heen, zin-bang,
zin-kleren-aandoen, zin-we-gaan-naar-buiten), gemaakt vlak vóórdat ze
vervangen werden door een geanonimiseerde versie (stemconversie naar
VCTK-spreker p256).

Herstellen: kopieer `recordings/*.webm` terug naar
`public/audio/recordings/`, en zet de entries uit
`recordings-manifest-man-entries.json` terug in
`data/recordings-manifest.json` (verwijder daarbij het veld
`voiceConverted` weer, want dat hoort niet bij een echte opname).
