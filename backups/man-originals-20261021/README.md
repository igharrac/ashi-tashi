# Backup: originele man-opnames (echte stem)

Dit is een snapshot van de echte, ongewijzigde man-opnames + hun
manifest-entries, gemaakt vlak vóórdat ze vervangen werden door een
geanonimiseerde versie (stemconversie naar VCTK-spreker p256).

Herstellen: kopieer `recordings/*.webm` terug naar
`public/audio/recordings/`, en zet de entries uit
`recordings-manifest-man-entries.json` terug in
`data/recordings-manifest.json`.
